# Xu Zirui Digital Room

This project uses React + Vite + TypeScript + Framer Motion. Do not reintroduce Next.js APIs.

- Run `npm run build` to typecheck and produce `dist`.
- Start with `npm run dev` on port 3000.
- Keep editable content in `src/data` and styles in `src/styles`.
- Preserve the four existing character PNGs and GIFs. Never substitute role-label blocks.
- Personal facts and publication stages come from the user's 2026-09-27 resume.
- Respect reduced-motion preferences, keyboard navigation, and mobile layouts.
- A Next.js baseline is archived in `migration-backup/next-baseline.zip`.
